# Exercise 1 — Create a file with nano and print it with cat

Read `week-07/materials/linux-basics.md`. On the course virtual machine, in `~/week-07`:

1. Create `hello.txt` with `nano`. Put your name on the first line and `Week 7 file` on the second line.
2. Run `pwd`, `ls -l hello.txt`, and `cat hello.txt`.

Copy `hello.txt` to `student_work/homework_answers/hello.txt`.

Paste the output of those three commands into `student_work/homework_answers/exercise_01.md`.
