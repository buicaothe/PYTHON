# Exercise 2 — Rename with mv and copy with cp

Start from `hello.txt` in `~/week-07`, the file from Exercise 1.

1. Rename `hello.txt` to `greeting.txt` with `mv`.
2. Copy `greeting.txt` to `greeting-copy.txt` with `cp`.
3. Run `ls -l`.

Copy `greeting.txt` and `greeting-copy.txt` to `student_work/homework_answers/`.

Paste the two commands and the output of `ls -l` into `student_work/homework_answers/exercise_02.md`.
