# Exercise 4 — Print your SSH config

Read `week-07/materials/ssh-config.md`. On your own computer, add a `Host 2026_deai_intro` block to `~/.ssh/config`. On the `User` line, write your own username on the virtual machine.

Print the file from Git Bash with `cat ~/.ssh/config`, or from PowerShell with `Get-Content $env:USERPROFILE\.ssh\config`.

Paste that output into `student_work/homework_answers/exercise_04.md`.

Paste the config only. Leave `~/.ssh/id_ed25519` unprinted.
