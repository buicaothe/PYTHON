# Exercise 0

__Please do this even if you already successfully inserted the SSH last week.__

Follow [vm-config/add-ssh-key-for-git.md](../../vm-config/add-ssh-key-for-git.md).

Generate a key with `ssh-keygen` if you do not already have one. Keep the default name `id_ed25519.pub`. Do not rename it, and do not add another extension.

Open `vm-config/put_your_ssh_public_key_inside_this_folder/` in GitLab. Use the **+** button and choose **Upload file**, then drag `id_ed25519.pub` into the commit window and commit the file.
